# Tahmin AI

Türkçe, macOS odaklı davranış senaryosu analiz uygulaması.

## İlk sürüm
Yerel SQLite hafızası, takma adlı kişi profilleri, gözlem kaydı, senaryo değerlendirme ve gerçekleşen sonuçların kaydı. Yapay zekâ entegrasyonu sonraki aşamadır. Gözlemler varsayımlardan ayrılır; doğrulanmamış olasılık yüzdeleri veya psikolojik teşhis üretilmez.

Kişisel veriler ve API anahtarları GitHub'a yüklenmemelidir. Yalnızca hukuka uygun ve izinli veriler kullanılmalıdır.

## Durum
Proje başlangıcı; henüz paketlenmiş veya test edilmiş bir macOS uygulaması değildir.
